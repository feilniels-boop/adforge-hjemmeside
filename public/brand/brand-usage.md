# AdForge Logo Usage

## Selected Concept
- Chosen direction: **Direction 1** (`refined/direction-1/`)
- Rationale: strongest brand fit by combining a bold **A** mark with a subtle creative-card cut, making it feel less like generic analytics and more like crafted ad production.

## Core Assets
- Primary horizontal: `adforge-logo-primary.svg`
- Primary horizontal monochrome: `adforge-logo-primary-mono.svg`
- Primary horizontal light (for dark backgrounds): `adforge-logo-primary-light.svg`
- Secondary stacked: `adforge-logo-stacked.svg`
- Icon only: `adforge-icon.svg`
- Icon monochrome: `adforge-icon-mono.svg`
- Favicon source: `adforge-favicon.svg`

## Color System
- Charcoal: `#18181B`
- Amber accent: `#F59E0B`
- White: `#FFFFFF`

## Clear Space
- Keep at least **0.5x** icon width as clear space around all logo lockups.
- Never place the logo directly against UI edges or CTA buttons.

## Background Rules
- Light backgrounds: use `adforge-logo-primary.svg`
- Dark backgrounds: use `adforge-logo-primary-light.svg`
- Single color print/use: use monochrome variants

## Do Not
- Do not stretch, rotate, or add effects.
- Do not recolor the icon bars independently.
- Do not use low-contrast combinations.
